 🎨 Pastel Palette Generator — создавай нежные цветовые палитры за секунду

> «Пастельные тона — это мягкость, теплота и вдохновение»

**Pastel Palette Generator** — это набор консольных утилит для генерации пастельных цветовых палитр.  
Программа создаёт случайные наборы пастельных цветов (с низкой насыщенностью и высокой яркостью) и отображает их в терминале с HEX-кодами, а также сохраняет в JSON, HTML и PNG.

## 🚀 Особенности
- 🎨 Генерация случайных пастельных цветов в формате HSL (Saturation 20–40%, Lightness 75–95%).
- 📊 Вывод палитры в терминале с цветными блоками и HEX-кодами.
- 📤 Экспорт в JSON, HTML (с CSS-переменными) и PNG (где реализовано).
- 🎛️ Настройка количества цветов (по умолчанию 5).
- 🔢 Поддержка seed для воспроизводимости.
- 🖥️ Цветной вывод в терминале с использованием ANSI-кодов.
- 📁 Пакетная генерация нескольких палитр (опционально).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости                          | Команда запуска                         |
|------------|--------------------------------------|-----------------------------------------|
| Python     | стандартная библиотека               | `python pastel_palette.py`              |
| Go         | стандартная библиотека               | `go run pastel_palette.go`              |
| JavaScript | Node.js, `fs` (встроенный)           | `node pastel_palette.js`                |
| Java       | стандартная библиотека               | `javac pastel_palette.java && java pastel_palette` |
| C#         | .NET (или mono)                      | `dotnet run`                            |
| Rust       | `rand` (для случайности)             | `cargo run`                             |
| Ruby       | стандартная библиотека               | `ruby pastel_palette.rb`                |
| PHP        | стандартная библиотека               | `php pastel_palette.php`                |
